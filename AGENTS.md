# AGENTS.md — trading-lab

Часть экосистемы `trdlabs`. Кросс-репозиторные вопросы — архитектура, контракты, раскатка,
локальный стек — из [`../control-center/AGENTS.md`](../control-center/AGENTS.md): там канонический
порядок чтения и карта владения. Соседа рядом нет (отдельный клон) — работать по локальным документам.

## Что это

Исследовательский мозг над торговой платформой: онбордит стратегию, выдвигает и проверяет
гипотезы об её улучшении, генерирует код-варианты, гоняет бэктесты в песочнице платформы и
выносит решение по каждому варианту.

**Research-only. Ничего не торгует вживую** — execution-адаптера нет физически. Сгенерированный
код исполняет только изолированная песочница платформы, не сам `lab`.

## Гейты

```bash
pnpm typecheck && pnpm test
```

Компоненты: `pnpm ingress` (входной HTTP), `pnpm worker` (очередь),
`pnpm platform:discover|validate|run|resume` (цикл), `pnpm analyst:eval` (оффлайн-оценка, читает
`.env`), `pnpm db:generate|db:migrate` (Drizzle).

## Правила и грабли

- **Инвариант research-only:** ничего исполняющего ордера не добавляется.
- Доступ к платформе — только через `@trading-platform/sdk` (read/sandbox), к бэктестеру —
  через `@trading-backtester/client`.
- Новые порты и адаптеры — по гексагональному образцу, тесты в `test/` обязательны.
- LLM-вызовы детерминировать где можно; в тестах проверять факт и аргументы tool-вызовов.
- Документация и уточняющие вопросы — на русском.
